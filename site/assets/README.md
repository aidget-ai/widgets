# Site assets

- `aidget-icon.png` is copied from the Aidget main repository at
  `icons/icon.png`.
- `product-preview.webp` and `product-window.webp` are the verified desktop and
  main-window captures used by the landing page carousel. Keep their intrinsic
  dimensions in sync with the generated markup and preview styles.
- `carousel.js` adds dot navigation, timed playback and reduced-motion
  behavior. Choosing a dot stops autoplay, and the first slide remains
  available without JavaScript.
