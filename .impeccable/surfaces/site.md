# Community Portal

## Scope

Persuade. Public GitHub Pages landing page for the Aidget community widget catalogue.

## Audience and action

Aidget users and newcomers browse rendered community widgets, then download the desktop app from GitHub Releases or follow an install action to the same official release page.

## Content and constraints

Every reviewed `registry.json` entry appears with its title, first screenshot, and description. The interface is bilingual, theme-adaptive, static, and self-contained. Author, version, platform metadata, search, filters, detail dialogs, download counts, and npm publication checks are outside this version.

## Direction contract

THESIS: Make the catalogue feel like the Aidget desktop app unfolded into a public showcase, with real widgets taking over a warm editorial product stage.  
OWN-WORLD: Cool app neutrals and a periwinkle-blue brand accent, soft raised surfaces, compact blue install pills, and the app's checkerboard preview stage.  
STORY: A visitor understands that Aidget turns desktop ideas into widgets, sees a product-image placeholder, then immediately recognizes the breadth of ready-made community cards.  
FIRST VIEWPORT: Compact product navigation; a large left-aligned promise and two actions; a wide image-led product stage beneath, partly framed by the warm desktop atmosphere.  
FORM: A full landing page followed by a three-to-one responsive catalogue grid; this is an extension of an established interface world.  
seed: none (unavailable)  
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
