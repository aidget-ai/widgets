# deepseek-whale-pendant · DeepSeek 鲸鱼娘 · 亚克力挂件

## 用途

透明桌面上的亚克力挂件复刻：吃饭场景的鲸鱼娘立绘加底部 DeepSeek 铭牌，边缘是半透明
玻璃刀模，高光跟随鼠标。原照片里的米色布纹背景和下方显示器桌面已扣除，只保留图案本体。

## 素材

- 图案由生图模型按实物照片复刻为 `1254 × 1254` 透明底图，再离线加工成 `700 × 692` 的
  RGBA PNG，作为运行期资源放在 `assets/pendant.png`，由 `style.css` 的 `--sil` 变量声明
  一次，可见层与遮罩层共用。`assets/screenshot.png` 只给社区卡片用，运行期不加载。
- 资源引用必须是包内相对路径：Aidget 只放行 `index.html`、`style.css` 和 `assets/**`，
  PNG 以 `image/png` 返回，CSP 的 `img-src` 与 `style-src` 已包含本地源。不要改成绝对
  路径或远程 URL，也不要为此往 `network` 里加源。
- 图案自带的白色贴纸描边（实测厚 14–20px）已按“到轮廓的深度”改成渐隐透明：环带内
  alpha 由约 0.14 的底色线性升到原值，深度 22px 处接回画面自己的深蓝描边。不要把这层
  重新涂成不透明白色，也不要反过来把整张图加一圈实心白边——凸起之间的缝隙会被糊住，
  看起来就像凸起被削平。
- 玻璃刀模是四圈向外偏移的轮廓，全部半透明：内侧高光线（半径 3、白 50%）、玻璃本体
  （半径 9、冷白 12%）、外缘亮边（半径 12、近白 38%）、外围冷色轮廓（半径 15、深蓝
  18%），并按左上打光做亮度渐变。半径刻意保持窄：刀模外扩会填平相邻凸起之间的窄缝。
  外围轮廓不能删，浅色桌面上的剪影靠它撑住。
- 素材四周自带 7.5%（约 53px）透明留白，挂件本体只占画布 85%。这圈留白用于消除
  “上方和左侧凸起被截断”的观感，同时保证玻璃边和投影不被窗口边缘切掉；不要为了填满
  画面收紧它。需要更大挂件就整体放大窗口，留白按比例跟着长。
- 必须完整保留：人物与饭碗、筷子、水滴与气泡、右侧红心气泡、底部 `DeepSeek` 铭牌
  （鲸鱼尾图标、蓝色文字、两端四角星）。

## 结构

- `main.stage` 带 `data-aidget-region="stage"`，可整体替换挂件结构；内部不要新增文字、
  底板或按钮。`<script>` 在 `main` 之外，patch stage 区域不会影响脚本。
- `.pendant-art`（可见层）与 `.pendant-shine`（遮罩层）共用同一个 `--sil`，轮廓只有一份
  数据；两层分别按 `background-size: contain` 与 `mask-size: contain` 居中，改画布边距时
  必须同步，否则遮罩与图案错位。
- 初始尺寸 `249 × 247`，与图案等比：本体约 212 CSS px，四边各约 18 CSS px 透明空隙。
  安装后窗口位置和尺寸归用户所有，内容更新不得移动窗口。
- 换图案只替换 `assets/pendant.png`；改动画布尺寸或留白时同步 `style.css`，否则遮罩与
  图案错位。`aidget_patch` 只适合改 HTML 结构，不能用来换二进制资源。
- 用 `aidget widget create` 建的本地开发副本没有写入 `assets/` 的通道，可能把同一张 PNG
  内联成 data URI；那是调试形态，不是发布形态，两边各自核对字节。

## 扫光（跟随鼠标）

- `.pendant-shine` 内含 `.shine-spot`（径向柔光）与 `.shine-streak`（斜向高光带），位置由
  `--mx` / `--my` 决定，整层被 `--sil` 遮罩限制在轮廓内，用 `mix-blend-mode: screen` 提亮，
  `isolation: isolate` 防止溢出到透明区。
- `index.html` 末尾的内联脚本通过 `window.aidget.onPointer` 接收宿主 hover 事件；
  `enter` / `move` 把 viewport 局部坐标写入 `--mx` / `--my` 并升到全亮，`leave` 回到
  静止位 `(30%, 20%)`、亮度 `0.42`。不要改回 DOM `pointermove`，也不要在窗口 `blur`
  时收掉高光，否则非活动窗口会失去跟随效果。
- `--shine` 初值必须保持 `0`：脚本未执行时挂件呈无高光降级态，截图里能否看到柔光也用来
  判断脚本是否运行。
- 扫光动画使用 `window.aidget.requestAnimationFrame`，按经过时间插值；收敛后停止申请帧。
  需要宿主提供该动画 API，不要改用 iframe 的原生帧时钟或增加常驻循环。
- `prefers-reduced-motion: reduce` 时脚本直接跳到目标值，不做插值跟随。

## 权限与外观

- `permissions` 仅 `["script"]`，只为扫光跟随鼠标；`network` 必须保持空数组，不加远程
  资源或数据请求。无外部数据、无定时刷新，除扫光外没有 CSS 动画。
- `dragMode` 为 `all`：拖动需要按下鼠标，不干扰悬停扫光。若宿主拖动吞掉指针事件导致
  扫光不动，改成 `handle`，不要删脚本。
- 使用 `aidget-surface="none"` 与透明页面背景；不要矩形底板、窗口材质，也不要用
  `backdrop-filter`（挂件页面背后没有可采样的内容，拖动时只会闪空白）。
- 保留图案本身的扁平赛璐璐上色，不要叠加新的调色滤镜。

## 平台

- 实现只用标准 HTML/CSS/JS，遮罩与高光定位均写 `-webkit-` 前缀版本，无构建步骤、无依赖。
- `config.json` 按仓库负责人要求声明全平台，与 `whalechan-acrylic` 和三个热搜组件同一
  口径。真实渲染验证目前只有 macOS（Aidget 截图加原生窗口抓取）；Windows 与 Linux 未做
  运行时确认，若遮罩或 `mix-blend-mode` 在别的内核上有差异，在实现层修，不要靠平台分支
  删效果。
