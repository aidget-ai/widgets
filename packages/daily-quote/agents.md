# 今日金句

## 结构与样式

这是日历式竖向金句卡片。保持浅色背景、深色文字、居中布局、大日期、分隔线与均衡的视觉留白（检查文字实际边界，不只比较 CSS 内边距），不添加底部品牌。日期、英文月份与中文星期由脚本按本地时区自动维护，不要手动修改。窗口位置和宽度由用户控制；更新内容时可按下方规则调整高度。

## 更新金句

- `quote`、`book`、`author` 是独立的 `data-aidget-region`，分别填写金句、出处和作者；每次更换金句同时更新三个区域。`book` 是保留的区域名称，内容不限于书籍。书籍或作品名称使用《》标注；没有可核实的作品出处时留空。
- 金句可以来自书籍、演讲或其他可靠来源。核实原文、作者和可提供的出处；无法核实时更换内容，不要编造或误归属。保持金句简短，确保小尺寸下也可读；以纯文本填充，转义 HTML 特殊字符。
- 先读取组件和当前 revision，优先使用 Aidget MCP 的 `aidget_patch` 一次原子更新三个 regions；若只有单区域 CLI，则以当前 revision 通过 `widget update` 一次更新完整 HTML，保留结构、日期脚本、样式和其他内容。revision 冲突时重新读取后再更新。
- 更新后截图检查文字完整、无裁切，并保持金句与出处之间的间距紧凑、上下视觉留白均衡。内容变化需要时，可调整窗口高度以完整展示内容：先读取当前 board revision 和窗口 frame，使用 Aidget board move 保留 display、x、y 和宽度，仅修改高度；遇到 revision 冲突时重新读取，保留用户的新位置和宽度，再按需调整并截图检查。
- 仅需 `script` 权限，不使用网络、存储或外部资源。本文件不创建或启用定时任务。
