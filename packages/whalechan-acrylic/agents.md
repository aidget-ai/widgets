# whalechan-acrylic · 鲸鱼娘 · 亚克力钥匙扣

## 用途

静态透明桌面钥匙扣，以完整鲸鱼娘立绘为主体，保留金属钥匙圈、亚克力刀模、
细边高光和轻微悬挂摆动。

## 结构与更新

- 设计尺寸为 360 × 220；窗口位置和尺寸归用户所有，内容更新不得移动窗口。
- 页面没有 `data-aidget-region`，因此不支持局部 patch；修改时必须整体替换文档。
- `.hardware` SVG 中包含交替椭圆链节、近乎闭合的圆形锁环和小挂环。保持它们居中、
  相互扣合，并与人物顶部打孔位置对齐。
- `.charm` 使用 `viewBox="-4 -2 188 188"` 预留刀模空间；顶部图钉孔、透明厚边、
  正面高光和完整脚部都依赖这些边界，不要收紧回图像的可见内容边界。
- 人物图已内嵌在 `#whalechan-art`。不要换回未加底部留白的桌宠原始 PNG，否则左脚鞋底
  会再次被位图边界截断。

## 权限与刷新

- `permissions` 和 `network` 均为空数组；不要加入脚本、远程资源或数据请求。
- 没有定时刷新或外部数据。悬挂摆动完全由 CSS 动画完成，并支持
  `prefers-reduced-motion: reduce`。

## 外观

- 使用 `aidget-surface="none"` 和透明页面背景；不要添加矩形底板、窗口材质或
  `backdrop-filter`。
- 保留细薄、略透的亚克力刀模边，以及只在边缘和曲线区域出现的高光。
- 角色、鲸鱼尾和米饭碗必须完整可见；鞋尖下方始终保留透明留白。

## 平台

- 目标平台为 macOS、Windows 和 Linux；实现只使用标准 HTML/CSS/SVG，不调用平台 API。
- 修改后仍需在 Aidget 中实际渲染并检查边缘、动画和完整人物，不能只依赖静态检查。
