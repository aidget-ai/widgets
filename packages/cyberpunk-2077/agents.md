# cyberpunk-2077 · 赛博朋克 2077

## 用途

透明桌面上的赛博朋克 2077 标识卡，用青色残影、故障切条和扫描光营造霓虹终端感。

## 可改区域

- `logo` 是整张卡片的唯一区域，包含完整的自包含 SVG 标识；替换内容时保留
  `data-aidget-region="logo"`。
- 源图尺寸为 688 × 216，随窗口等比缩放并居中。默认窗口为 360 × 220，位置和尺寸由用户控制。

## 权限与刷新

- `permissions` 和 `network` 均为空数组。不要加入 JavaScript、远程资源或数据请求。
- 无定时刷新；故障与扫描动画完全由 CSS 循环完成。
- 在 `prefers-reduced-motion: reduce` 下停用动画，并保持标识清晰可见。

## 外观

- 页面声明 `aidget-surface="none"`，使用无边框透明表面。保持 `html`、`body`、
  `.logo-stage` 和页面背景透明。
- 主标识使用 SVG 内嵌位图保留原始颜色；青色残影、故障切条和扫描光只是叠加装饰，
  不要替换主标识本身。
- 不使用 `backdrop-filter`，避免 macOS 拖拽时背景模糊消失导致闪烁。
