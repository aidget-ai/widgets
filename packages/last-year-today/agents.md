# 去年今日

## 用途

这是静态的「去年今日」记忆卡片：一张全出血的推测场景图，左上角写着一年前同一天的日期，左下角留一句克制的格言。卡片本身不查询记忆，也不按日期自动翻页；内容由 Agent 在需要时人工更新。

## 内容区域

- `date-day` 只放日期中的数字日，保留内部 `time` 元素及其 `datetime` 属性。
- `date-meta` 放英文月份和年份、星期，例如 `/ November` 与 `2025, Tue`。
- `memory` 放一句与当天回忆有关的留白式格言，保持一到两行。
- 优先一次读取当前 revision，再用 Aidget MCP 的 `aidget_patch` 原子更新三个区域；遇到 revision 冲突时重新读取，不要覆盖用户同时做出的修改。

## 更新记忆

- 从用户可用的记忆与历史记录中查找去年同日的真实活动，优先选择一件具体、可核实的事。不要绑定某个固定数据源；按现有工具和记录找到证据即可。
- 根据这件事推测一个克制、有氛围、没有文字和 Logo 的现实场景，再生成或更换背景。画面不能伪造可识别的人像与真实照片。
- 正文不要复述资料清单；从当天的具体事件中提炼一句有余味的格言。找不到任何可核实记录时，明确写“去年今天，没有留下记录”或留空，不要编造经历。
- 日期必须和回忆对应当天，不能沿用旧日期；更新后同步修改 `time` 的 `datetime`。

## 背景与文字对比

- 初始背景以 CSS data URI 内嵌在 `--scene-image`。换图时生成约 1440 × 880 的 WebP，确认没有文字、Logo、水印和人物，再压缩后整体替换这条 CSS 变量；不要引入远程图片或网络权限。
- 先看背景的实际明暗再决定文字颜色。暗背景用白色文字加现有暗角与底部渐变；亮背景改用深色文字和浅色 scrim。任何选择都要以截图确认日期、正文和背景边界清楚可读为准。
- 画面主体尽量放在右侧或中部，给左上日期和底部正文留出低干扰空间。不要用 `backdrop-filter` 作为可读性的唯一依靠。

## 布局与权限

- 默认窗口是 360 × 220，位置和尺寸归用户控制；更新内容或背景时不得移动窗口，也不要因为一次截图的效果擅自改窗口尺寸。
- 仅为静态 HTML/CSS，不需要 `script`、`storage` 或 `location` 权限，`network` 必须保持为空。不要加入定时任务、远程字体、远程图片或运行时依赖。
- 改完内容后截图检查日期准确、正文无裁切、两行内可读、圆角和边缘完整；若文字压到亮处，调整 scrim 或换一张更适合排版的图。
