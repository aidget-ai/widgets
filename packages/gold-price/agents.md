# 黄金价格卡片

## 用途

展示上海黄金交易所黄金 9999（AU99.99）的最新价、日内涨跌幅和日内走势。数据来自东方财富公开行情接口，不代表交易所官方直连。

## 区域与布局

- `quote`：品类标签、涨跌幅和大号最新价。涨跌幅按昨收计算，上涨显示正号，下跌显示负号；文字始终保持白色。
- `chart`：原生 SVG 日内面积图。金色折线表示收盘价走势，金色虚线表示昨收，右下圆点表示最新位置。
- 窗口固定为 180×180，外边距约 12px；内容卡片使用深海军蓝背景和金色强调色。窗口位置与尺寸归用户控制，内容更新不得移动窗口。

## 数据与刷新

- 数据源：`https://push2.eastmoney.com/api/qt/stock/trends2/get`，`secid=118.AU9999`。
- `data.preClose` 为昨收，`data.trends` 每行逗号分隔字段中的第三项为收盘价；最后价格与昨收计算涨跌幅，价格精度使用 `data.decimal`。
- 页面加载后立即获取一次行情，之后每 5 分钟使用单一定时器刷新，禁止重叠请求。
- 请求或字段校验失败时，价格和涨跌幅显示 `--`，涨跌幅位置显示“行情加载失败”，清空图表并等待下一周期重试；不得缓存旧行情、伪造数据或切换备用源。
- 首次渲染或错误状态完成后调用 `window.aidget.ready()`。

## 权限与资源

- 仅启用 `script` 权限，网络白名单仅允许 `https://push2.eastmoney.com`。
- 不启用 `storage` 或 `location`。
- 不加载远程脚本、字体、图片或第三方图表库；视觉资源全部由本地 HTML、CSS 和 SVG 生成。
