# 倒数日

## 用途

这是一张多事件倒数卡片。包内初始内容是“纪念日 / 元旦”两个真实示例；页面按本地日历日计算，一次显示一个事件，事件多于一个时可在左下角左右切换。

## 设置事件

- 先读取当前组件和 revision。使用 `aidget_patch` 更新 `events` 区域，保留外层 `data-aidget-region="events"`。
- 区域内按顺序放置一个或多个 `<article class="event-data" data-event data-event-repeat="...">`；顺序就是切换顺序，至少保留一个事件。
- 每个事件包含 `h2[data-event-title]`、`time[data-event-date]` 和可选的 `p[data-event-note]`。日期写入 `datetime` 属性并使用有效的 `YYYY-MM-DD`，显示文字由页面生成。
- 重复周期值只能是 `once`、`weekly`、`monthly` 或 `yearly`，分别表示一次性、每周、每月和每年。周期只用于计算，不显示在卡片上。
- 只提供事件数据，不要添加计数、按钮、页码、周期标签或目标日期详情；页面会生成这些内容。事件名尽量不超过两行，说明保持在两行以内。
- 事件多于一个时页面自动显示左右切换，只有一个时隐藏切换控件。
- 示例区域内写 HTML 时，转义事件名称和说明中的 `&`、`<`、`>`；不要加入脚本、外部资源或事件处理属性。
- 修改时一次原子 patch 整个 `events` 区域，避免残留旧事件。遇到 revision 冲突时重新读取，勿覆盖用户同时做出的更改。

## 日期规则

- 日期没有时区，按本地日历日计算；目标日当天显示 0 天。
- 一次性日期未来显示剩余天数，过去显示已过去天数。
- 每周以设定日期的星期为锚点；每月以设定日为锚点；每年以设定月日为锚点。重复周期都倒数到下一次出现的日期。
- 每月遇到较短月份时落到该月最后一天；闰日遇到非闰年时落到 2 月 28 日。
- 不要猜测或编造用户的事件、日期和说明。日期为空或设置无效时，卡片会显示错误。

## 外观与权限

- 保留暖白底、钴蓝色卡片、柿橙点缀、前景大号数字和左下角切换控件；不要移动或调整用户窗口。
- 卡片使用本地日期脚本，只需 `script` 权限。`network` 保持为空；不使用 `storage`、远程字体、图片或依赖。
